## Problema

Os quiosques e ecrãs táteis em espaços públicos (receções, lojas, hospitais, câmaras municipais) ficam muitas vezes "presos" num ecrã de uma utilização anterior ou saem da aplicação. Também não dão uma experiência simples a quem chega.

## Solução

Uma aplicação de informação em **ecrã inteiro**, pensada para ecrãs táteis grandes, que:

- apresenta um menu de informação claro e com botões grandes
- **volta automaticamente ao ecrã inicial** após um período sem interação
- esconde as barras do sistema (**modo imersivo**) para o utilizador não sair da app

## Tecnologias

- Kotlin
- Android Views (XML) + Material Design 3
- Android Studio

## Como executar

1. Clonar o repositório:
   ```bash
   git clone https://github.com/elisamanuel-on/smartspace-kiosk.git
   ```
2. Abrir a pasta no Android Studio (**Open**).
3. Aguardar a sincronização do Gradle.
4. Executar num emulador de **tablet** (recomendado: Pixel Tablet, API 34+).
